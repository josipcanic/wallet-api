# Route Map

## System

- `GET /`
- `GET /health`
- `GET /api-docs`

## Users

- `POST /users/register`
- `POST /users/login`
- `GET /users`
- `GET /users/:id`
- `PUT /users/:id`
- `DELETE /users/:id`

## Wallets

- `POST /wallets`
- `GET /wallets`
- `GET /wallets/:id`
- `POST /wallets/:id/deposits`
- `DELETE /wallets/:id`

## Transfers

- `POST /transfers`
- `GET /transfers`
